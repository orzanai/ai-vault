# 04 · TEAM: run a team of AI agents while you sleep

From the reel: *"Most people run one AI agent. I run a whole company of them."* → [@orzan.ai](https://instagram.com/orzan.ai)

**Paperclip** is free, open-source, self-hosted orchestration for teams of AI agents: an org chart, tasks, budgets and approvals in one dashboard. *"If OpenClaw is an employee, Paperclip is the company."* Commands are copied from the project's README (checked 2026-11-13).

https://github.com/paperclipai/paperclip · MIT · 113K+ ⭐

---

## 1. Install (no account needed)
Requires **Node.js 24.11+**.
```bash
npx paperclipai@latest onboard --yes
```
Or hand the official install guide to your agent: https://docs.paperclip.ing/reference/cli/installation/

New? Follow the 5-minute path: https://docs.paperclip.ing/guides/getting-started/five-minute-path/

## 2. The 3 steps
1. **Define the goal.** Make it specific and measurable, e.g. *"Get my app its first 100 users"*.
2. **Hire the team.** A CEO, engineer, marketer… Each agent can run a different harness or model (Claude Code, Codex, OpenClaw and more).
3. **Approve and run.** Review the strategy, **set budgets** (company, agent or project), turn on **approval gates**, then hit go.

## 3. "While you sleep"
- **Heartbeats** wake agents for assigned work, follow-ups, or on a **schedule**.
- **Routines** run recurring work (reports, social, support) on a schedule or via webhook, each with a run history.
- **Budgets** send alerts and **pause work at your limit**, so a runaway loop can't drain your account overnight.
- You can monitor and approve from your phone.

## Good to know
- Paperclip is free; **the agents use your own API keys or subscriptions**, so watch the budgets.
- Start small: 2–3 agents and one clear goal. A vague goal gives vague work (garbage in, garbage out).
- Keep approval gates on for anything that publishes, spends or touches production.
